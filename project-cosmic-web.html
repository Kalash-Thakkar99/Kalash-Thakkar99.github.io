COSMIC WEB · GRAPH NEURAL NETWORKS

Learning the Cosmic Web.

Can graph neural networks classify galaxies by cosmic-web environment—and still work when they are moved from one cosmological simulation to another?

Utica University · remote collaborationSupervisor: Dr. Unnati ShahAug 2026 — PresentCurrent research

ON THIS PAGE

MotivationRepresentationPipelineTransferCurrent status

01 / MOTIVATION

The cosmic web is naturally relational.

Galaxies are not isolated points. Their local and large-scale environments emerge from spatial relationships: filaments, nodes, sheets and voids. Graph neural networks offer a way to represent those relationships directly rather than treating each galaxy independently.

02 / REPRESENTATION

Turn a galaxy catalogue into a graph.

The project uses CAMELS catalogues with ground-truth cosmic-web labels produced through a first-principles tidal-tensor (T-web) pipeline. Galaxies become graph nodes, their spatial relationships define edges, and the network learns an environmental classification.

galaxies → graph geometry → message passing → web environment

04 / GENERALIZATION

Domain shift is the point, not a nuisance.

The project explicitly measures degradation when a model trained on TNG is evaluated on SIMBA or Astrid without retraining. Macro F1, MCC and confusion-matrix analysis make the transfer failure—or success—quantifiable.

TransformerConv and GPSConv architectures are being explored as comparative baselines under the same evaluation protocol.
